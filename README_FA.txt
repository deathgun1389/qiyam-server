سرور آنلاین قیام ایرانیان — نسخه آماده استقرار

فایل‌ها:
- server.js: سرور بازی و WebSocket
- package.json: فرمان اجرای استاندارد Node.js

تنظیمات هاست:
1) محتوای ZIP را در ریشه پروژه استخراج کنید؛ package.json باید در ریشه باشد.
2) فرمان Start را روی npm start قرار دهید (یا npm install && npm start).
3) پورت برنامه باید از متغیر محیطی PORT گرفته شود؛ اگر پنل پورت 3000 می‌دهد، نیازی به تنظیم دستی نیست.
4) دامنه عمومی باید HTTPS داشته باشد و پراکسی هاست باید WebSocket را عبور دهد.
5) برای آزمایش وضعیت: https://YOUR-DOMAIN/health
6) آدرس سرور داخل بازی باید wss://YOUR-DOMAIN باشد، نه لینک GitHub و نه آدرس HTTP.

این نسخه وابستگی npm ندارد. داده‌های پایدار در پوشه data ذخیره می‌شوند؛ مطمئن شوید هاست اجازه نوشتن در این پوشه را دارد.

توجه: سازگاری پروتکل بر اساس فایل سرور قبلی پروژه حفظ شده است. اجرای موفق روی هاست به تنظیمات پورت، دامنه و پشتیبانی WebSocket آن هاست نیز وابسته است.
